# ConectaMercado 🛒

O ConectaMercado é uma plataforma desenvolvida para facilitar a experiência de compra em supermercados, permitindo que os usuários consultem a disponibilidade de produtos em tempo real antes de sair de casa.

O projeto surgiu a partir da identificação de uma dor recorrente enfrentada por consumidores: deslocar-se até um supermercado e descobrir que o produto desejado está indisponível. Além de reduzir o desperdício de tempo e custos com deslocamento, a solução busca oferecer mais praticidade, especialmente para idosos, pessoas com mobilidade reduzida e consumidores que desejam planejar melhor suas compras.

Objetivos
Consultar a disponibilidade de produtos em supermercados parceiros.
Reduzir deslocamentos desnecessários.
Economizar tempo e dinheiro dos consumidores.
Melhorar a experiência de compra por meio da tecnologia.
Apoiar supermercados com uma plataforma moderna de comunicação com seus clientes.
Funcionalidades
🔍 Consulta de estoque em tempo real.
📍 Busca por supermercados participantes.
🛒 Pesquisa rápida de produtos.
📱 Interface intuitiva e responsiva.
📊 Protótipo desenvolvido para validação da solução junto aos usuários.
Tecnologias

React

(As tecnologias serão atualizadas conforme o desenvolvimento do projeto.)

Projeto Acadêmico
